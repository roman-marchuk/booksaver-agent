# Context

BookSaver remains one owner/invite local daemon. Booking.com inventory owns reservation facts; the coordinator owns admission and session-scoped price jobs. Price/inventory adapters return untrusted evidence. Browser host infrastructure owns confinement and cleanup. SQLite owns durable account, history and migration contracts. Tests own fakes and canonical packaged replay inputs. specs.md artifacts own lifecycle state; Git refs identify active or retired work. This cleanup removes alternate obsolete writers and test-only runtime contracts without changing those authorities.
